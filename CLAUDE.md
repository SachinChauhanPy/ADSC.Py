# ADSC.Py Project Commands

## Development
- Run dev server: `npm run dev`
- Build production bundle: `npm run build`
- Run typecheck: `npm run typecheck`
- Lint code: `npm run lint`
- Preview production build: `npm run preview`

## Codebase Guidelines
- **Styling**: TailwindCSS is used for styling.
- **Routing**: Routes are defined in [routes.ts](file:///d:/ADSCPY/adsc.py/src/routes.ts).
- **Core Components**: Layout files are in `src/components/layout/`. Page components are in `src/pages/`.
